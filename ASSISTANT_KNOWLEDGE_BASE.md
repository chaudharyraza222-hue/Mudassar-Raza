# Sellrix - App Knowledge Base

This document describes all features, pages, and workflows in the Sellrix app. Use this as reference when answering user questions about how to use this specific app.

## Overview

Sellrix is a seller operations and Amazon listing management tool. It helps sellers:
- Manage product listings and their Amazon presence
- Monitor and adjust prices dynamically (repricing)
- Generate AI-powered product titles and descriptions
- Create and manage product images
- Bulk import products from spreadsheets
- Source products from competitor/supplier links

## Pages and Features

### 1. Dashboard
- **Purpose**: Main landing page showing seller overview and navigation to all features
- **What it displays**:
  - Seller account name and workspace info
  - Quick stats and status
  - Navigation links to all major features
- **What you can do**: Click on any feature card to navigate to that section

### 2. Listings Page
- **Purpose**: View, manage, and create product listings
- **What it displays**:
  - Table of all your products
  - Product name, SKU, brand, category
  - Current status (draft, live, etc.)
  - Filters to view by status (All, Live, Drafts)
- **What you can do**:
  - Click on a listing to view/edit full details
  - See tabs filtering listings by status
  - Create new listings or import from spreadsheet
- **Listing Statuses**:
  - Draft: Not yet submitted to Amazon
  - Live: Active on Amazon
  - Inactive: Paused/hidden on Amazon

### 3. Listing Detail Page
- **Purpose**: View and edit a single listing with all fields and generated content
- **Main Sections**:
  - **Basic Info**: Product name, brand, SKU, category, subcategory
  - **Pricing**: Current sell price, cost, calculated profit, profit margin %
  - **Description & Content**: Generated title and bullet points
  - **Images**: Main image and gallery images
  - **Auto-fix Panel**: Three-column preview showing:
    - Source link values (fetched from competitor/supplier)
    - AI-generated values (generated by AI model)
    - Manual review items (fields needing review)
- **What you can do**:
  - Edit any field directly
  - Run Auto-fix to populate fields from source links and AI
  - Preview changes before submitting
  - Submit listing to Amazon

### 4. Sourcing Page
- **Purpose**: Add new products by fetching metadata from source links and bulk import from CSV/spreadsheet
- **Manual Add Section**:
  - Enter source link (competitor/supplier page URL)
  - Enter product name, brand, SKU
  - Click "Add Source Product" to fetch title and main image automatically
  - Results show: fetched title, image, and success/failure reason
- **Bulk Import Section**:
  - Upload a CSV or spreadsheet file with columns: source_link, competitor_link, product_name, brand, sku
  - Click "Import rows" to start bulk import
  - Progress shows: "Fetched X of Y"
  - After import completes, shows summary: number fetched successfully, number failed, and row-by-row details with failure reasons
  - Common failure reasons: "link unreachable", "no title found on page", "no image found on page"

### 5. AI Content Generation Page
- **Purpose**: Generate product titles and descriptions using AI
- **What you can do**:
  - Enter or paste existing product title and description
  - Click "Generate Title" to create AI-powered product title
  - Click "Generate Bullets" to create 5 selling bullet points
  - Results show AI-generated content ready to use
  - Copy generated content to your listing
- **AI Model**: Uses Google Gemini API (if configured), otherwise returns mock/template content

### 6. Image Generation & Library
- **Purpose**: Manage product images and generate AI images
- **Image Library Tab**:
  - View all uploaded/saved product images
  - See image preview and metadata
- **Generate Images Tab**:
  - Enter product description or use existing
  - Click "Generate Image" to create AI image mockup
  - Results show generated image preview
- **Image Management**:
  - Images are stored in /static/images/library/
  - Main image is the first one displayed on listings
  - Gallery images are additional product photos

### 7. Repricer Page
- **Purpose**: Manage dynamic pricing based on competitor/supplier prices
- **Product List**:
  - Shows all products with their current sell price
  - Current rule (percentage or fixed dollar amount profit margin)
  - Source links and current prices
- **How Repricing Works**:
  - System checks all supplier sources for each product
  - Automatically selects the cheapest "In Stock" source
  - Calculates minimum profit margin (% or $) you need
  - Recommends new sell price based on cheapest source + your profit margin
  - Example: If cheapest source is $10 and you want 20% profit, recommended price is $12
- **Source Status**: "In Stock" or "Out of Stock"
  - Only in-stock sources are considered for repricing
  - System ignores out-of-stock competitors
- **What you can do**:
  - View current repricer rule and sources
  - See recommended prices
  - Update source stock status if needed

## Key Workflows

### Workflow 1: Add a New Product from a Competitor Link
1. Go to **Sourcing** page
2. In "Manual Add" section, paste competitor/supplier product link
3. Enter product name, brand, SKU
4. Click "Add Source Product"
5. System fetches title and main image automatically
6. Review the fetched data
7. (Optional) Go to Listing Detail and click "Auto-fix" to also fetch AI-generated content
8. Click "Submit" to create the listing

### Workflow 2: Bulk Import Many Products
1. Prepare CSV file with columns: source_link, competitor_link, product_name, brand, sku
2. Go to **Sourcing** page
3. In "Bulk Import" section, upload your CSV file
4. Click "Import rows"
5. Watch progress: "Fetched 1 of 50", "Fetched 2 of 50", etc.
6. When done, see summary: "25 fetched successfully, 5 failed"
7. Review failed rows to see why (link unreachable, no image found, etc.)
8. All successfully imported products appear in Listings

### Workflow 3: Generate AI Content for a Listing
1. Go to **AI Content** page
2. Enter your existing product title and description
3. Click "Generate Title" to get AI-powered title
4. Click "Generate Bullets" to get 5 selling points
5. Review AI output
6. Copy the generated content to your listing (Listing Detail page)
7. Save/submit listing

### Workflow 4: Set Up Dynamic Pricing with Repricing
1. Go to **Repricer** page
2. View your products and their current price
3. Review source links and their stock status
4. System automatically uses the cheapest in-stock source for price calculations
5. Check recommended prices based on your profit margin rule
6. Pricing updates automatically as competitor prices change

### Workflow 5: Auto-fix a Listing (Fill Missing Fields)
1. Open a listing in **Listing Detail**
2. Click "Auto-fix" button
3. System attempts to populate missing fields in this order:
   - STEP 1: Tries to fetch from source/competitor link
   - STEP 2: Falls back to AI generation for remaining gaps
   - STEP 3: Shows preview in 3 columns (source-fetched, AI-generated, manual review needed)
4. Review the preview
5. Accept changes or manually edit fields
6. Click "Submit" to save

## Data & Status Fields

### Listing Fields
- **SKU**: Stock Keeping Unit (unique product identifier)
- **Product Name**: Full product title for Amazon
- **Brand**: Manufacturer or brand name
- **Category**: Amazon product category
- **Subcategory**: Specific category tier
- **Current Sell Price**: What you're selling it for on Amazon
- **Cost**: What you paid for the product
- **Profit**: Calculated as (Sell Price - Cost)
- **Profit Margin %**: Calculated as (Profit / Sell Price) * 100

### Common Error Messages & What They Mean
- "link unreachable": The source URL couldn't be accessed (site down, bad URL, network issue)
- "no title found on page": Page was accessed but title metadata wasn't found
- "no image found on page": Page was accessed but product image couldn't be extracted
- "API_ERROR": Issue calling Google Gemini API (check API key or quota)

### Product Status Meanings
- **In Stock**: Available from supplier/competitor
- **Out of Stock**: Not currently available
- **Needs Review**: Content needs manual verification before publishing
- **Live**: Currently active on Amazon
- **Draft**: Not yet submitted to Amazon

## Important Notes

### About Source Links
- Source links are URLs pointing to competitor or supplier product pages
- System fetches product title from page metadata (og:title or <title> tag)
- System fetches main image from page metadata (og:image or <img> tag)
- Source links must be accessible from the internet (not internal/private URLs)
- If a source link fails to fetch, you can manually enter title and image

### About AI Generation
- Requires Google Gemini API key to be configured
- Without API key, system returns template/mock content
- AI content should be reviewed before publishing to Amazon
- You can edit any AI-generated content manually

### About Repricing
- Only active when pricing rules are set
- System always uses the cheapest in-stock source
- Out-of-stock sources are ignored
- Profit margin can be set as percentage (20%) or fixed amount ($5)
- Repricing helps you stay competitive with automatic price adjustments

### About Bulk Import
- CSV must have column headers: source_link, competitor_link, product_name, brand, sku
- Each row creates one new product
- If a source link fails for one row, other rows continue processing
- Failed rows are logged with specific reason (you can retry later)
- All images are automatically saved to the image library

## Buttons & Actions Explained

- **"Add Source Product"**: Fetch title and image from a single source link
- **"Import rows"**: Start bulk import of CSV file
- **"Generate Title"**: Use AI to create a product title
- **"Generate Bullets"**: Use AI to create 5 selling bullet points
- **"Generate Image"**: Use AI to create a product image mockup
- **"Auto-fix"**: Automatically populate missing listing fields from source link + AI
- **"Submit"**: Save/publish listing to Amazon
- **"Repricing"**: View dynamic pricing recommendations

## Technical Notes (For Understanding How Things Work)

- Titles are limited to 200 characters on Amazon
- Bullet points are typically 85-200 characters each
- Images should be square or nearly square for best display
- Prices are stored in USD
- Profit calculations are before taxes and shipping costs
